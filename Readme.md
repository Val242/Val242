## 🚀 About Me

I'm a Full-Stack Software Engineer who builds web and mobile applications, designs backend APIs, and works with databases to deliver complete software solutions. My experience spans frontend development, backend engineering, and application architecture.

Alongside software development, I'm actively building my DevOps and cloud engineering skills, focusing on AWS infrastructure, Infrastructure as Code, CI/CD automation, Linux administration, and application observability.

I enjoy understanding the complete software lifecycle—from turning requirements into functional applications to deploying, monitoring, and improving the systems that run them.

- 💻 **Full-Stack Development:** Building web and mobile applications with React, Next.js, React Native, Expo, and modern JavaScript/TypeScript technologies.
- 🔧 **Backend Engineering:** Designing REST APIs and backend services with NestJS, Node.js, PostgreSQL, Prisma, Java, and Spring Boot.
- 🗄️ **Database Engineering:** Working with relational and document databases, data modeling, database integration, and ORM-based persistence.
- ☁️ **Cloud Engineering:** Developing practical AWS skills in infrastructure provisioning, networking, access management, and cloud operations.
- ⚙️ **DevOps & Automation:** Building skills in Terraform, Ansible, Linux, Bash, GitHub Actions, and automated deployment workflows.
- 📊 **Monitoring & Observability:** Working with Prometheus, Grafana, and related monitoring tools.
- 🏗️ **Software Architecture:** Applying modular design, separation of concerns, and system design principles to build maintainable software.

My approach is to understand the problem, design the solution, build it deliberately, test it, and progressively improve how it is deployed and operated.
