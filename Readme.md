## 🚀 About Me

I'm a Software Engineer focused on backend development, cloud infrastructure, DevOps automation, and reliable system design.

I enjoy understanding how systems work beyond the application code—from designing APIs and relational data models to provisioning cloud infrastructure, automating deployments, and monitoring applications in production-like environments.

- 🔧 **Backend Engineering:** Building REST APIs and backend applications with NestJS, Node.js, TypeScript, Prisma, Java, Spring, Spring Boot, and Hibernate.
- ☁️ **Cloud Engineering:** Provisioning and managing AWS infrastructure with Terraform.
- ⚙️ **DevOps & Automation:** Working with Linux, Ansible, Bash, GitHub Actions, and automated deployment workflows.
- 📊 **Observability:** Implementing application metrics and infrastructure monitoring with Prometheus, Grafana, and related tools.
- 🗄️ **Database Engineering:** Designing relational data models and working with PostgreSQL and Prisma ORM.
- 🏗️ **System Design:** Exploring distributed systems, architectural trade-offs, scalability, and reliability.
- 🔐 **Security:** Practicing secure credential management, AWS IAM, OIDC-based authentication, and dependency scanning.

My approach is simple: understand the problem, design the system, implement it deliberately, automate what can be automated, and verify that it works.
